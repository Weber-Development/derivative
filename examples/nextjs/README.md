# Next.js example

Next.js App Router with `WhatsNew` from `@sweberdev/derivative-react` in the root layout.

```sh
pnpm install
pnpm dev
```

`pnpm changelog` turns `CHANGELOG.md` into `public/changelog.json` before `dev` and `build`. The component is a client component, so `app/layout.tsx` can stay a server component.
